# Reflected Cross-Site Scripting (Reflected XSS)

**Platform:** OWASP Juice Shop v20.2.0

**Category:** Cross-Site Scripting (XSS)

**Status:** Successfully Completed

## Overview

This report documents the identification and exploitation of a Reflected XSS vulnerability through the Order Tracking URL parameter.

## Technical Highlights

- Identified the `id` URL parameter as an injection point.
- Performed iframe-based XSS payload injection.
- Successfully triggered a JavaScript alert popup.
- Verified challenge completion.
